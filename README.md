# iDepth 26 Wallpapers — v1.6.1

Projeto Android `com.chilenoapps.idepth26` — ChilenoAPPS.

## Visual aprovado
- preto profundo + amarelo premium;
- cards arredondados e bordas discretas;
- miniaturas preenchendo o card até a borda;
- grade de wallpapers em 2 colunas;
- navegação inferior em cápsula;
- Ajustes em cartões expansíveis;
- Studio com preview em tempo real antes de aplicar.

## VIP
O entitlement final é a soma de:
1. assinatura válida pela Google Play; ou
2. liberação administrativa no Supabase para teste/suporte/promoção.

O Painel Admin permite **Ativar VIP** e **Desativar VIP** para o aparelho atual e para instalações registradas. Nenhum CPF, senha ou segredo fica dentro do APK.

## Build local

